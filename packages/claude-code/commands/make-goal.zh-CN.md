# Make Goal / 制作 Goal

你正在使用通用 `make-goal` 工作流。请把用户的复杂目标整理成一个可执行的 `goal.md`，让其他 AI agent 能够读取后长期循环执行、验证并完成任务。

用户请求：

`$ARGUMENTS`

## 指令

1. 如果缺少关键上下文，先提出简短澄清问题。
2. 检查用户提供的文件、目录、仓库、示例或链接。
3. 默认匹配用户语言；用户要求时输出中英文双语版本。
4. 写出自包含的 `goal.md`，必须包含：
   - 目标
   - 背景
   - 需要检查的参考资料
   - 范围和假设
   - 约束
   - 执行 harness 和环境：运行时、工具、依赖安装、权限、密钥、外部服务、就绪检查、降级方案
   - 交付物
   - 带验收标准的里程碑
   - agent 工作循环
   - 进度记录
   - 验证计划
   - 风险和阻塞规则
   - 质量标准
   - 完成定义
5. 如果用户提供了路径，就把 `goal.md` 保存到该路径；如果没有路径，询问保存位置或先在对话中草拟。
6. 写入后验证文件存在，并简要总结结果。

除非用户明确要求，否则不要直接完成底层项目。你的任务是创建可长期执行的 goal 文档。
