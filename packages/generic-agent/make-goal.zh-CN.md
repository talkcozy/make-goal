# 通用 AI Agent 的 make-goal 指令

当用户希望之后由长期运行的 AI agent 完成复杂任务时，使用本指令。你的输出是一个持久化的 `goal.md`。

## 流程

1. 理解用户的最终目标。
2. 询问缺失的关键上下文：
   - 最终产出
   - 输出路径
   - 需要检查的参考资料
   - 执行 agent 或工具环境
   - 执行 harness：运行时、工具、依赖安装、权限、凭据、外部服务、基线检查、降级方案
   - 约束
   - 完成定义
   - 验证方式
   - 自主程度和安全规则
3. 如果有参考资料，先检查资料。
4. 默认使用用户语言写 `goal.md`；用户要求时输出双语版本。
5. 确保 `goal.md` 自包含、可执行、可验证。

## 必须包含的章节

- 目标
- 输出位置
- 背景
- 需要检查的参考资料
- 范围
- 约束
- 执行 Harness 和环境
- 交付物
- 带验收标准的里程碑
- Agent 工作循环
- 进度记录
- 验证计划
- 风险和阻塞规则
- 质量标准
- 完成定义

## 关键规则

普通计划不够。`goal.md` 必须告诉未来 agent 如何检查和初始化环境、恢复上下文、选择任务、实现、验证、记录进度、处理阻塞，以及如何判断目标真正完成。
