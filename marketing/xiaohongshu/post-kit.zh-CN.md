## 简介

很多 AI 长任务失败，不是因为目标不清楚，而是环境、验证、进度和阻塞处理没有写进一个稳定文件。`make-goal` 会先把复杂目标整理成可执行的 `goal.md`，再让 Codex、Claude Code 或其他 agent 长时间推进。

核心理念：你必须非常努力，才会看起来毫不费力。

项目地址：https://github.com/talkcozy/make-goal

### Cover

主标题：复杂需求别直接丢给 AI

副标题：先生成一个能长期执行的 goal.md

角标：make-goal

### 01

标题：为什么长任务会烂尾？

要点：

- 计划只在聊天记录里
- 环境依赖没有写清
- 验证方式靠临时记忆
- 下一轮 agent 接不上

### 02

标题：goal.md 不是待办清单

要点：

- 目标和边界
- 上下文和参考资料
- 里程碑和验收标准
- 进度记录和恢复方式

### 03

标题：真正关键的是 Harness

要点：

- runtime 和 package manager
- CLI、插件、MCP、服务
- 环境变量和权限
- 缺失依赖时的 fallback

### 04

标题：正确交给 Agent 的方式

要点：

- 让它先读仓库
- 自己安装 make-goal
- 验证 skill 可用
- 再生成并执行 goal.md

### 05

标题：适合这些长期任务

要点：

- 软件重构
- 产品 MVP
- 研究报告
- 文档迁移
- 游戏开发
- 知识库清理

结尾：前面越认真，后面越省心。
